**Yooos TLOU Editor** is a community-developed asset browser and 3D world editing tool for The Last of Us Part II Remastered.

Explore game assets, inspect 3D models, browse textures and metadata, and build custom scenes through an intuitive editing environment.

Designed for modders, creators and technical artists, Yooos TLOU Editor brings asset exploration and world editing together in one workspace.

**Features**
- Native game asset catalogue
- 3D model inspection and preview
- Asset search and filtering
- Scene creation and object placement
- Transform tools and viewport controls
- Customizable keyboard shortcuts
- Performance-focused asset loading

An independent community project. Not affiliated with or endorsed by Naughty Dog or Sony Interactive Entertainment.
